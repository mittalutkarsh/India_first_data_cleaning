Quality Filter

Per Quality_Filter.md: decide whether each document is good enough to train on. Nine cheap checks score it, a content profile protects legitimate lists/code/chat, and every document is routed — not silently deleted.

How to read this page

Each document gets nine quick quality measurements. Each has a pass zone (shaded green on its gauge); a marker shows where this document lands. The document is then routed:

✅ KEEPClears the checks — goes into training.
📄 KEEP (special)A list, code or chat — kept, but normal prose rules don’t apply.
🟠 REVIEWBorderline or too short — held for a closer look.
⬜ DROPSpam, repetition or symbol-soup — excluded.

There is no single right cut-off. The strictness slider below selects a named policy bundle (from threshold-selection.md): drag it and watch the pass zones and every verdict move. This is Layer 1 (fast heuristics); a learned quality classifier (Layer 2) is a documented offline tier, not run here. Hover any underlined term for its meaning.
