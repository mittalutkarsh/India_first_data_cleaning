PII & Redaction

Per PII.md: find personal data, decide from entity type + context + source, replace only the necessary spans with typed placeholders, and route the document — without erasing public attribution, organisations or places.

⚠️ Every identifier on this page is synthetic / fake (example.com, standard test card, invented Aadhaar/PAN/keys). A real run never displays raw PII — note the detection table below shows only typed placeholders, never the value.
How to read this page

Each document is scanned for personal data. Every hit gets a risk tier and an action (mask / pseudonymize / keep), then the whole document is routed:

✅ KEEP (scrubbed)PII replaced with placeholders; the text is kept.
🔴 QUARANTINEA secret, a sensitive attribute, or strong IDs — held for governed handling.
⬜ EXCLUDEPrimarily a personal-record dump — dropped entirely.

The decision depends on the source (a public figure is kept in the news but pseudonymized on a forum) and on the policy. The slider selects a named policy bundle (from policy-and-thresholds.md) from least to most aggressive. Full multilingual NER and quasi-identifier linkage are a documented offline tier.
