How to read these pages

A few conventions run through every stage:
  • Plain verdicts — a colour-coded badge (KEEP / REVIEW / DROP / …) with a one-sentence reason.
  • A strictness slider — most stages have named policy bundles; drag it and every verdict re-computes live.
  • Hover-to-learn — any dotted-underlined term shows a plain-English tooltip.
  • 🧪 synthetic vs real — hand-made examples tour the tricky cases; the rest are real Hindi Wikipedia.
  • Offline tiers — heavy models (fastText, embeddings, a real tokenizer) are noted where a browser can’t run them.
